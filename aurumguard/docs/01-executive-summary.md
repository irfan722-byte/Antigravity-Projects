# 01 Executive summary

AurumGuard is a rule-based XAU/USD (spot gold) analysis, risk-management, paper-trading and mobile-notification application. It evaluates the market continuously on four horizons (scalp, intraday, swing, weekly hold) and returns exactly one of six statuses per horizon: **BUY SETUP, SELL SETUP, WAIT, NO TRADE, EVENT LOCKOUT, DATA UNAVAILABLE**. A setup is issued only when data integrity, strategy rules, regime approval, evidence independence, cost-adjusted reward-to-risk, position sizing and all twenty hard gates pass. Every decision carries a full Evidence Inspector and is recorded immutably; outcomes are written separately after expiry.

What is delivered in this repository (`aurumguard/`):

- **Backend** (Python 3.11, FastAPI, SQLAlchemy, Alembic): market-structure engine with objective definitions, regime engine, explainable evidence scoring with correlation collapsing, twenty hard gates, risk manager and position sizer, four candidate strategies in a formal registry, news-event state machine, deterministic paper-trading engine, bias-resistant backtester with walk-forward validation, Monte Carlo, cost and threshold sensitivity, calibration, notification service with deduplication/throttling/quiet hours, hash-chained audit log, JWT/Argon2 auth with optional TOTP MFA, provider abstraction with a complete mock set and one real (unverified) adapter.
- **Frontend** (Next.js 15, TypeScript, Tailwind 4, Serwist PWA, lightweight-charts): 26 pages, installable PWA with Web Push service worker, light/dark theme, i18n and RTL scaffold, accessibility basics.
- **Operations**: Dockerfiles, docker-compose, Terraform skeleton, GitHub Actions CI (lint, static security analysis, migrations, tests, build, secret and dependency scanning), `.env.example` files with names only.
- **Verification performed in this session**: 69 backend tests pass (unit, integration, API, data-integrity, risk, paper engine, backtest reproducibility, news state machine); frontend typecheck, lint and 7 unit tests pass; production build compiles. See `35-pre-production-checklist.md` and `36-production-readiness-assessment.md` for what was **not** verified.

Honest status: **the MVP runs end-to-end in DEMO mode on synthetic data.** No strategy has been validated on licensed market data, no provider licence has been confirmed, no legal review has been done, and push delivery has only been exercised with the mock provider. The application is therefore **not production-ready** and says so in its own admin dashboard. It is a complete, testable foundation whose remaining work is data licensing, real validation, security review and compliance, not missing features.
