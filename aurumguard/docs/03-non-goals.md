# 03 Non-goals (explicitly excluded from the MVP)

- Automatic live order execution or any broker connectivity (the boundary is designed but disabled and unimplemented).
- Guaranteed returns, win-rate promises or any performance claim not backed by a labelled sample.
- Hidden, insider, leaked or non-public data; claims about institutional intent or "manipulation".
- Unauthorised scraping of any website or data feed.
- Copy trading, signal selling, social features.
- Martingale, grid averaging into losses, loss-based scaling, stop widening, autonomous risk-limit changes.
- Self-modifying or self-promoting strategies; LLM-based trade decisions.
- Instruments other than XAU/USD (futures, silver, FX pairs are used only as intermarket evidence).
- Native mobile apps (the PWA is the mobile surface; the API is native-ready).
- Arabic translation content (only the i18n/RTL architecture is included).
